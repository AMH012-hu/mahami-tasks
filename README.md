# مهامي (Mahami)

Arabic RTL task and project manager. Static installable PWA: plain HTML, CSS and JavaScript. Tasks are stored only in the browser (IndexedDB) on the user's device; there is no server and no sync. Use Settings to export or import a backup.

Files: `index.html`, `app.js`, `style.css`, `sw.js` (offline cache), `manifest.webmanifest`, `icons/`.
